# Portfolio Site

Personal portfolio — dark, Tron/Encom-inspired theme with a live GitHub activity feed and a
featured project write-up for [Beeper](https://github.com/GHurley4444/beeper).

Plain HTML/CSS/JS, no build step. Open `index.html` directly or serve the folder statically
(GitHub Pages, Netlify, etc.).

## Structure

- `index.html` — content and structure
- `style.css` — theme, layout, animations
- `script.js` — boot sequence, scroll-reveal, nav scroll-spy, live GitHub stats fetch
