// 02  FEATURED PROJECT

Beeper

A handheld cybersecurity gadget, built from a bare ESP32 dev board up — custom firmware, passive recon tools, and hand-wired power/audio hardware.

Beeper runs on a "Cheap Yellow Display" ESP32 board (ESP32-2432S028R) with a TFT_eSPI display and XPT2046 resistive touchscreen. The firmware is a fully custom, touchscreen-driven system with its own menu architecture, screen state machine, and persistence layer — no off-the-shelf app framework.

◉

Passive Recon Tools

Read-only WiFi scanner, BLE scanner with AirTag/Tile tracker detection, and a Bluetooth Classic scanner. No injection or pairing — observation only.

▣

From-Scratch QR Engine

A QR code generator and renderer built without an external library, driven straight from the touchscreen UI.

◉

Prescript Game Engine

A touchscreen menu system (GAME · CITY · CON · TASK · TIMED) with Easy/Normal/Hard/Rare difficulty tiers, streaks, and run history.

⚡

Hand-Wired Hardware

3000mAh LiPo battery through a load-sharing charge/boost circuit, a Class-D amp driving small speakers via an RC filter, breadboard-prototyped end to end.

C++ / Arduino ESP32 TFT_eSPI XPT2046 Touch WiFi / BLE APIs Embedded Systems Circuit Design
Firmware repo is private — available on request.
