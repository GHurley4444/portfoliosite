Password Checkup

A client-side password strength meter, breach checker, and generator. No password ever leaves the browser in plaintext — everything runs locally, including the cryptography.

← ALL PROJECTS

Concept

A small toolkit rather than a single trick: analyze a password's real strength, check it against known breaches, and generate a strong replacement — all without a backend, and without the password itself ever touching a server in readable form.

What It Does

◉

Strength Meter

Scores length, character variety, and obvious patterns (sequences like abcd/1234, repeated runs, common passwords) entirely offline, live as you type.

◎

Crack-Time Estimate

Translates the same entropy math into plain English — time-to-crack under a rate-limited online attack (100/sec) and a fast offline attack (10B/sec). A known common password shows as instant in both, since real attackers check dictionaries before brute-forcing.

▣

k-Anonymous Breach Check

Hashes the password with SHA-1 via the Web Crypto API and sends only the first 5 hash characters to Have I Been Pwned's Pwned Passwords API — the match against the full hash happens locally, so the server never learns which password was checked.

⚡

Random Password Generator

Configurable length and character sets, drawn via crypto.getRandomValues with proper rejection sampling — not % modulo, which biases toward lower values.

●

Diceware-Style Passphrases

Draws from the real EFF Large Wordlist (7,776 words, ~12.9 bits of entropy each) with optional capitalization, an embedded number, and a configurable separator.

The Privacy Model

Every check is designed so the password never leaves the browser in a form anyone could reverse:

  1. The browser hashes the password with SHA-1 using the native Web Crypto API.
  2. Only the first 5 characters of that hash are sent to the HIBP API.
  3. The API returns every breached hash suffix sharing that 5-character prefix — typically hundreds of candidates.
  4. The match against the full hash happens locally, in the browser.

This is the k-anonymity model HIBP designed specifically for this use case. The breach check also only fires on an explicit button click, never on every keystroke, so nothing is sent while a password is still being typed.

Tech Stack

Vanilla JavaScript Web Crypto API k-Anonymity HIBP Pwned Passwords API EFF Diceware Wordlist
