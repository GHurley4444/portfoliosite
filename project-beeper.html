Beeper

A handheld device inspired by Rein's Beeper and The Index from the Project Moon universe (Limbus Company, Library of Ruina) — recreated as real, hand-wired hardware.

← ALL PROJECTS

Inspiration & Concept

Beeper is built on two references from the Project Moon universe: Rein's Beeper from Limbus Company, and The Index from Library of Ruina. The physical device recreates the former; its core behavior recreates the latter — in the source material, The Index hands out a single type of prescript. This build expands that into five parallel categories (GAME, CITY, CON, TASK, and a TIMED variant), each with its own difficulty pools and history — a personal design layer on top of the reference, not a lore-accurate recreation.

Everything past that core loop — the lyrics viewer, tarot, oracle, cipher wheel, and the WiFi/BLE/BT recon tools — is additional: some built purely for fun, some as practical cyber tools, sitting alongside the main task-issuing function rather than part of it.

What It Does

Runs on a "Cheap Yellow Display" ESP32 board (ESP32-2432S028R) with a TFT_eSPI display and XPT2046 resistive touchscreen. The firmware is fully custom — its own menu architecture, screen state machine, and persistence layer, with no off-the-shelf app framework underneath.

◉

Prescript Task Engine

Five themed menus (GAME, CITY, CON, TASK, TIMED) each issue prompts to complete, with Easy/Normal/Hard/Rare difficulty tiers, no-repeat shuffled decks, streak tracking, and persistent run history.

◉

Passive Recon Tools

Read-only WiFi scanner (sorted by RSSI), BLE scanner with AirTag/Tile tracker detection via manufacturer-data pattern matching, and a Bluetooth Classic scanner. No association, pairing, or injection.

▣

From-Scratch QR Engine

A QR v1 (ECC-L) encoder built without an external library, complete with its own Reed-Solomon GF(256) tables, rendered straight to the touchscreen.

♪

Lyrics Viewer

An original song catalogue with per-song visual effects (particles, glitch, waves, fire) driven by a scramble-reveal text renderer shared with the main task screens.

●

Side Tools

Coin flip, tarot draw (22 Major Arcana with its own persisted shuffle deck), an 8-ball oracle, countdown timer, word generator, and a Caesar cipher wheel.

⚡

Hand-Wired Hardware

A 3000mAh LiPo through a load-sharing charge/boost circuit, a Class-D amp driving small speakers through an RC filter, breadboard-prototyped end to end.

Every prescript string here is copied straight out of beeper.ino's own easy*, *Prescripts, hard*, and rare* pools — nothing written for the site. GAME, CON, and TASK issue short all-caps directives; CITY keeps the Index's original sentence-style phrasing.

Use the arrows to swipe between categories, the way the device's touchscreen carousel works. Hit PASS or FAIL to draw the next prescript — two PASSes in a row bump the difficulty tier, one FAIL drops it back to Easy. TIMED pulls from each category's rare pool and runs on a live countdown, same as the on-device timer menu.

Hardware Build

The CYD board has no native battery input, so power had to be solved separately from the display/logic board itself.

  • BATTERY3.7V 3000mAh LiPo cell, JST 1.25mm connector.
  • CHARGE / BOOSTLoad-sharing charger/booster so the battery can charge and power the board simultaneously off USB — the CYD's own regulator can't do this alone.
  • AUDIOClass-D amplifier into small 8-ohm speakers, with an RC filter added to clean up output on a free GPIO.
  • PROTOTYPINGEntirely breadboard-wired before any permanent assembly, with connector-pitch mismatches (1.25mm vs 2.0mm JST) solved via re-terminated leads.
