Cybersecurity Capstone

A team-based cybersecurity capstone at Towson University — standing up a full Active Directory lab, running a simulated penetration test against it end to end, and delivering a formal CVSS-scored report, alongside hardening and defending Windows Server, Windows 10, and Ubuntu Linux systems.

The Exercise

Towson University's Cybersecurity Capstone (Spring 2025) put teams in charge of an enterprise-style environment spanning Windows Server, Windows 10, and Ubuntu Linux. The build stood up a full Active Directory lab, then ran a simulated penetration test against it end to end — reconnaissance through exploitation — closing with a formal, CVSS-scored report, alongside the defensive side: keeping services correctly configured and monitored against the vulnerabilities that assessment surfaced.

What I Worked On

◉

Service Hardening

Secured SSH, Apache, and SMB across the environment — closing default configurations and unnecessary exposure before they could be used as an entry point.

◎

Monitoring & Detection

Watched the environment with Graylog and Wireshark, correlating log activity and packet captures to catch what was actually happening on the network in real time.

▣

Active Directory Lab

Stood up a full AD environment as the target for the exercise — domain, group policy, and the kind of realistic misconfigurations that make AD such a common attack surface in the real world.

⚡

Offensive Assessment

Ran a simulated penetration test end to end with Kali Linux and Nmap — reconnaissance through exploitation — against the team's own AD environment.

●

CVSS-Scored Reporting

Closed the assessment with a formal report: each finding scored by CVSS severity and paired with a concrete remediation — the deliverable a real client engagement would expect.

◉

Enterprise System Administration

Managed Windows Server, Windows 10, and Ubuntu Linux hosts side by side, including firewall rules and the database services running on top of them.
